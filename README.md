# 🌍 REST Countries Explorer

A modern and responsive web application built using **React.js** that allows users to explore countries around the world using the **REST Countries API**.  
Users can search for countries, filter by region, and switch between light and dark themes.

---

## 🚀 Live Demo  
🔗 https://countries-detail-app.netlify.app

---

## 🛠 Tech Stack  
- React.js  
- JavaScript (ES6+)  
- HTML5  
- CSS3  
- REST Countries API  

---

## ✨ Features  
- Search countries by name  
- Filter countries by region  
- Light and dark theme toggle  
- View detailed information for each country  
- Responsive design for all screen sizes
